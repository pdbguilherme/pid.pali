# Identificadores persistentes · PRPPG/UNESPAR

Guia interativo para docentes e discentes dos Programa de Pós-Graduação da UNESPAR sobre os identificadores
persistentes que devem ser criados, mantidos e informados à CAPES.

## O que o guia oferece

- Roteiro em ordem, com checklist, para docentes e para discentes
- Orientações sobre ORCID, Lattes, Scopus, ResearcherID (Web of Science),
  OpenAlex e Google Acadêmico
- Passo a passo para informar os identificadores no Meus Dados da CAPES
- Orientação aos discentes sobre como solicitar o e-mail institucional
- Validação dos códigos e exportação de um PDF para enviar à coordenação
- Perguntas frequentes

## Privacidade

Os dados digitados na página ficam salvos apenas no navegador de quem os
preencheu. Nada é enviado ao programa nem a terceiros.
